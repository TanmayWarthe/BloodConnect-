# BloodConnect

Welcome to the BloodConnect repository! 🚀 This project consists of two primary components: the backend and frontend.

## Table of Contents
- [Backend](#backend)
- [Frontend](#frontend)
- [Environment Variables](#environment-variables)

## Backend

This project uses **Spring Boot** version **3.2.2** with **Java 17** and **MySQL**. The backend server runs on port **8080**.

### Project Structure
- `src/`: Contains the main Spring Boot application code.
- `pom.xml`: The Maven configuration file for dependencies.

## Frontend

The frontend is built with **React** version **19** using **Vite**, **Tailwind**, and **Leaflet**. It runs on port **5173** by default.

### Project Structure
- `src/`: Contains all React component code.
- `public/`: Static assets for the frontend.
- `.env.example`: Example configuration for environment variables.

## Environment Variables

Make sure to reference the `.env.example` file located in the frontend directory for environment variable notes. Ensure that all environment variables are set appropriately for both the backend and frontend.

Please adjust your directories and clone URL as necessary to reflect this structure! 🌟
